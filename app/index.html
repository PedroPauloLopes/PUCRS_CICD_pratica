Projeto DevOps na Prática

Curso de Análise e Desenvolvimento de Software - PUCRS

Integração Contínua • CloudFormation • AWS • GitHub Actions

Sobre o Projeto

Este projeto foi desenvolvido como atividade acadêmica da disciplina DevOps na Prática, pertencente ao curso de Análise e Desenvolvimento de Software da PUCRS.

O objetivo é aplicar conceitos modernos de DevOps, automação, integração contínua e infraestrutura como código utilizando ferramentas amplamente utilizadas no mercado.

Tecnologias Utilizadas

  • Git e GitHub
  • GitHub Actions
  • AWS CloudFormation
  • Amazon S3
  • Docker
  • HTML5 e CSS3

Objetivos da Atividade

  • Configurar um pipeline de Integração Contínua (CI)
  • Automatizar processos de build e deploy
  • Provisionar infraestrutura utilizando IaC
  • Realizar integração com serviços AWS
  • Aplicar boas práticas de DevOps

Status do Projeto

Ambiente inicial configurado com GitHub Actions, AWS CloudFormation e sincronização automática com Amazon S3.
